# Original native GUI payload declarations

This three-path proposal is bound to source `c7306544c6d2e9fb4ed74bf6c4031a1c5555310b` and workflow `cf9657782fb1d4bdae3991fcd9a5db1b7d62e6de`. `BINDINGS.json` contains exact Git blob IDs and full pre/post SHA-256 bindings. The packet supplies four real payload declarations needed by the original Update; it contains no Update entry, caller, callback selection or preparation activation.

`CgsGui::GuiEventGetLanguage` is the original four-byte language enum reply. DecFIGS h289 names `mLanguage`, and ARTIST AddGuiOutEvent `8250C134/138` supplies size4/id31 from the caller's object address. The old generic twelve-byte prefix is removed from this concrete reply. The current source only names this type in its declaration and existing explicit publisher instantiation; no selected producer is changed.

`CgsGui::GuiEventNetworkConnected` retains size2/id43 and now names the two DecFIGS bools at bytes0/1: `mbIsFirstLogin` and `mbIsNewsUpdated`. The genuine output publisher `82566098/9C` attests that size and id, while the native Update reads the news byte at+1. Both actual network state-manager producers are changed only from `maData[0/1]` to the names of those same two members. Their getter calls, request order and publisher calls remain byte-identical after reversing those four identifier expressions.

`BrnGui::GuiMugshotControlEvent` retains size24/id325 and receives the real field-only declaration: road CgsID at0, response enum8, image enum12, opponent active-race-car index16 and local-aggressor bool20. DecFIGS h1052..1056 names and types those fields. ARTIST AddGuiEvent `823D0984/88` publishes24 bytes from the object address, and the Update reads response8. The four existing producers already overwrite the complete meaningful raw payload at exactly these positions. They stay unchanged; there is no wrapper stripping, additional copy or altered producer. Natural alignment now follows the genuine CgsID field; the queued payload remains aligned to16 by the existing queue owner.

`BrnGui::GuiResponseTimeDateString` retains size36/id594 and now contains its actual request word and32-byte text buffer. ARTIST `82529428..82529538` stores the request at stackvar310 and formats the string atvar30C, then publishes the object beginning atvar310. The publisher `8250C1EC/F0` passes36/id594. The inspected DecFIGS export supplies no declaration for this response; `muRequestID`/`macString` are explicit host projections of those two real fields, not claimed original spellings. No payload prefix or extra storage is introduced.

These are field-only queue payloads. The old generic `GuiEvent<N>` embeds a transport header and cannot serve as their data base. The common empty CgsModule::Event wire root preserves conversion to the actual queue API without supplying fabricated data. This packet does not generalize or repair the remaining controller/music template-family encodings.

All selected templates and publisher bodies are retained as exact provider snapshots. The network producer C++ file is already shipping-mounted, as are the existing GUI/network publisher instantiation TUs. No CMake or shipping source-roster changes are needed.
