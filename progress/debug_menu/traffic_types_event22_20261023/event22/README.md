# Event 22 road-rule sound trigger recovery (source-only proposal)

This proposal recovers the full original event-22 chain without changing the generic OutputGuiEvent template. The X360 publisher at ARTIST 0x824368F0 copies a payload-only 100-byte body and queues {100, 22, 12} + payload on channel 40 (112 bytes). The current host CgsGui::GuiEventSoundTrigger has a 12-byte GuiEvent<22> header before its fields, so passing that host type directly would put the strings/layer at the wrong offsets and send raw id 22, which the current flow-output switch drops.

The producer delta replaces that call with a local payload-only view whose fields are type[32], action[32], label[32], and layer@96, then builds GuiEventWrapper<...,40> and submits exactly 112 bytes. The receiver delta handles only the exact {100,22,12} record after the existing channel-40 unwrap. It reads the layer at payload offset 96, resolves the movie through ViewModule::GetMovieNameByLevel, and invokes the existing FlaptSoundTriggerCallback. That callback uses the same 14-action name table and GuiAudioTriggerEvent::Construct behavior recovered in PC source, producing current typed event 201. The existing sound receiver accepts the PC 201 full record and the ARTIST 457 raw-payload representation.

The event-22 record remains on the existing module-output/observer fan-out path; the added callback appends its audio event after that record. This is flagged as a PC adapter because this host flow pump has no module-input loopback to GuiModule::Update for event 22.

preimage/, postimage/, and patch.diff contain the exact source-only delta. bindings.json records file hashes and original address bindings. Exact ARTIST exports and DecFIGS declarations are included under evidence/. The current 508/509, raw155, and raw201 decoder paths are captured to make compatibility preservation reviewable. The same evidence folder includes a 66-row route matrix from the codex08-captured source snapshot; codex08 labels its base 7e455d, but this lane did not independently read the 7e, 6e, or e306 Git trees. It distinguishes the 65 direct generic call sites mapped to these ARTIST rows from the 70-call global scan, and keeps unresolved sinks marked uncertain. Candidate-specific packet dispositions are separate in evidence/candidate_delta_notes.tsv. It is a route audit, not a claim that every current debug registration was verified.

No production source, Git state, compiler, tests, game, Stage, Run, or input were touched. Proposal source preimages and postimages are SHA-256 pinned; the exact source base commit identity remains a composing-owner check because this lane did not run Git.
