# GUI channel-40 action publication batch

This is a source-only proposal based on B5 `af18caf8a9e02428cfaa4705599e2b1ca9ea7377` from `git show`. The physical parent is `8d67d4c0e93db58f28f774137deed688582764e6`; the shared B5 checkout was clean at `91a0ed564f9c9e3dec915bfb416c0467650084ef`. The current debug-menu campaign README was read and left unchanged.

The proposal changes five call sites across four files. Three publish `GuiEventActivateCrashNav` through the generic `OutputGuiEvent` path. That C++ event object already contains the complete 20-byte X360 output record `{8,191,12}+8`; the proposal queues those same bytes on channel 40, without adding another wrapper. Two Showtime results call sites publish the raw one-byte `GuiEventShowHideHud`; the proposal boxes that payload with the existing `GuiEventWrapper<T,40>`, producing the X360 record `{1,148,12}+1` (16 bytes).

The original ARTIST exports bind `OutputGuiEvent<GuiEventActivateCrashNav>` to `0x82493938` and `OutputGuiEvent<GuiEventShowHideHud>` to `0x82493988`. The first writes `{8,191,12}` plus eight caller bytes and queues channel 40 / 20 bytes. The second writes `{1,148,12}` plus one caller byte and queues channel 40 / 16 bytes. `ShowtimeInstantResultsState::OnEnter` independently writes the same event-148 record inline at `0x824C5D28`; `Update` calls the named publisher at `0x824DFB48`.

The current PC `DrainFlowOutputQueue` already decodes channel 40 by reading payload size, inner id, and payload offset, then forwards and routes the unwrapped event. Its default drops direct queue ids 148 and 191. Thus the proposed caller changes use the decoder already present. The matched consumer paths are GameModule event 191 and the HUD-flow event-148 handlers.

A global `OutputGuiEvent<T>` rewrite is outside this batch. The 66 explicit ARTIST instantiations all queue on channel 40, but the PC types include both payload structs and types that already hold the complete record. Other in-tree compatibility includes direct video ids 508/509, and `GuiOverlayRequest` requires a 16-byte payload offset. A single unconditional wrapper or direct pass would corrupt some of those paths. The full 66-row ARTIST header/type/offset/queue-size audit is in [artist_outputgui_66.tsv](artist_outputgui_66.tsv).

The proposed patch is [proposal.patch](proposal.patch). Its source ownership is limited to `BrnOnlinePlay.cpp`, `BrnCrashNavSettings.cpp`, `BrnCrashNavDriverDetails.cpp`, and `BrnShowtimeInstantResults.cpp`. It does not edit the shared publisher, decoder, overlay producer, Root's autosave work, any Graphics-owned file, refs, index, or campaign inventory. No source files outside this new scratch directory were changed. No compile, test, CI, native/game, Stage, Run, or input action was performed; this proposal carries no build or behavior credit.
