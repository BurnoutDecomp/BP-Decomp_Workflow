# Historical frame cleanup

Deleted 7,673 historical frame dumps after the user requested bulk scratch cleanup. The deletion ledger records every path. About 30 GB was recovered; D: free space rose from 2.46 GB to 32.25 GB at measurement.

Kept first/middle/last frames per historical frame directory (2,003 files), recent captures, contact sheets and all 48 current minimap frames. Source, saves, configs, logs and evidence archives were not deleted. Normal build/profile/config and current frozen test inputs were reverified unchanged.

Old test records can now reference intentionally deleted raw frames. The retained representatives, logs and published contact sheets remain; this cleanup does not assert that deleted frames can be restored. No new debug-menu site is verified by cleanup.
