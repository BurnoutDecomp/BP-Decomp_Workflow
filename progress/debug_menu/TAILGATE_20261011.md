# Batch 1: tailgate controls

The five sliders under Race Car Entity / Tailgate... changed debug globals while
the detector and boost-credit consumer read independent constants. This made the
menu values and cone drawing disagree with gameplay.

## Original evidence

ARTIST `RaceCarEntityModuleDebugComponent::OnActivate` at `822C2538` registers:

| Label | Original data | Reader |
| --- | --- | --- |
| Cone HalfAngle (Rads) | `82CDB4B4` | detector `822CE3C4..822CE44C` |
| Cone Depth | `82CDB4B8` | detector `822CE364..822CE3B8` |
| Min Duration | `82CDB4BC` | boost `82304B34..82304B44` |
| Max Relative Speed | `82FAD3F0` | detector `822CE474..822CE48C` |
| Min Tailgate Speed | `82CDB4C0` | detector `822CE458..822CE464` |

The shared cone-reference offset is `82CDB4B0`; it is also read at `822CE354`.
DecFIGS `dwarfdump/GameSource/World/EntityModules/RaceCarEntityModule/BrnRaceCarEntityModule.cpp`
names all six globals at original lines 368..373. The detector's final `fcmpu; ble`
takes unordered comparisons too; boost's `bgt` requires strictly greater duration.

- Nearby production regressions: submenu parents 5/5, component activation 41/41,
  rival damage/takedown lifecycle 39/39.

The first fixed attempt stalled in BOOT before reaching changed code. A second
fixed attempt exposed an overly long typing sequence that lost the event's rival
cars. These are retained as inconclusive/failed runs, not counted as passes. The
case now uses the existing F2..F7 bindings to complete all stages before teardown.
An earlier baseline replay hit `CgsSound::TestBed::Allocator::SortedDump` after
audio allocation failure, before the menu sequence completed; it is inconclusive
for tailgating. The successful replay above supersedes it. The verified fixed
sources and executable were restored after each baseline build/staging operation.

The case deliberately sets broad/extreme debug values and injects event start,
one second of throttle and a teleport through existing harness controls. It proves
debug-control behavior, not organic tailgating balance. The real save/INI are untouched.
